# Media

Drop files here with these exact names. The gray frames on the site fill in
automatically on the next build. Set `youtube` ids for the documentaries in
`lib/site.ts`.

| File | Where it shows | Shape |
| --- | --- | --- |
| apl-showcase.jpg | Home (large) and the APL page | 4:3 |
| portrait.jpg | Home, next to the showcase photo | 4:5 |
| apl-architecture.png | APL page (a diagram you draw) | 4:3 |
| bid-pipeline.png | SalesPatriot page (screenshot) | 16:10 |
| mustcheck-scan.png | MustCheck page (phone screenshot) | 9:19.5 |
| mustcheck-score.png | MustCheck page (phone screenshot) | 9:19.5 |

Videos work too: use .mp4 or .webm and update the file name in `lib/site.ts`.
Keep photos under ~500 KB (export at 2000px wide, JPEG quality ~80).
Nothing from inside APL or NSA without written approval.
